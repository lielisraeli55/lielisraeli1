# Biometric Auth

אתר אימות דו-שלבי בדפדפן: טביעת אצבע (לחיצה ממושכת) ואחריה סריקת פנים במצלמה, עם אזהרה קולית כשהפנים מכוסות.

## שימוש

פתח את `index.html` בדפדפן מודרני (Chrome / Edge / Firefox / Safari) דרך `https://` או `http://localhost` — נדרשת הרשאה למצלמה ולמיקרופון.

הרצה מקומית:
```bash
python3 -m http.server 8000
# http://localhost:8000
```

## זרימה

1. **טביעת אצבע** — לחץ והחזק על העיגול 2 שניות עד שהטבעת הירוקה מתמלאת.
2. **סריקת פנים** — המצלמה נפתחת אוטומטית. טיימר של 4 שניות רץ רק כשפניך גלויות.
3. **כיסוי פנים** → מסך אדום מהבהב + ביפ + הכרזה קולית *"נא לא לכסות את הפנים"*, הטיימר נעצר.
4. **הצלחה** — מסך "האימות הצליח" עם צ'ק מאנימציה.

## טכנולוגיה

- **MediaPipe Face Detection** (Google) — זיהוי פנים בזמן אמת בדפדפן
- **Web Audio API** — ביפ אזהרה
- **Speech Synthesis API** — הכרזה קולית בעברית
- HTML/CSS/JS טהור בלי build tools
