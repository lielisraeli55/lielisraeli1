# Access Control – Face Recognition

מערכת בקרת גישה בדפדפן: מעלים תמונות פנים של אנשים מורשים, והמצלמה סורקת בזמן אמת. אם הפנים במצלמה תואמות לאחד שנרשם — "אדם מורשה". אחרת — "אדם לא מורשה". אם הפנים מוסתרות, נשמעת אזהרה קולית.

## שימוש

פתח את `index.html` דרך `https://` או `http://localhost` (דרוש עבור גישה למצלמה). נדרש דפדפן מודרני.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## זרימה

1. **הוספת אדם מורשה** — הכנס שם, לחץ "בחר תמונה" ובחר תמונה ברורה של הפנים. ייווצר תמונה ממוזערת וייוצר embedding (128-d) לזיהוי.
2. **הפעל סריקה** — המצלמה נפתחת, הפנים מזוהות ונמדדת הדמיון מול כל תמונה שהעלית.
3. **תוצאה בזמן אמת** —
   - ירוק: "אדם מורשה" + שם + ביפ + הכרזה קולית
   - אדום: "אדם לא מורשה" + ביפ + הכרזה
   - צהוב: "אין זיהוי פנים — גלה את פניך" כשהפנים מכוסות
4. מעל תיבת הפנים על הווידאו מופיע תג "מורשה/לא מורשה" וציון דמיון.

## טכנולוגיה

- **@vladmandic/face-api** — TinyFaceDetector + FaceLandmark68Net + FaceRecognitionNet (TF.js)
- **Web Audio API** — ביפי אזהרה/אישור
- **Speech Synthesis API** — הכרזה קולית בעברית
- כל הנתונים (תמונות, embeddings) שמורים בדפדפן בלבד, לא נשלחים לשרת.

## סף ההתאמה

`MATCH_THRESHOLD = 0.55` (מרחק Euclidean על ה-128-d embedding). ככל שהערך קטן יותר — מחמיר יותר. אפשר לכוון ב-`script.js`.
