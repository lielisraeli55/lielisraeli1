# Air Touch — שליטה ביד מרחוק

מסך-בית וירטואלי שנשלט בתנועות יד דרך מצלמת הטלפון. מצביעים באצבע — סמן זוהר עוקב. צובטים (אגודל ואצבע נפגשים) — האפליקציה מתחתיו נפתחת.

## שימוש

פתח את `index.html` דרך `https://` או `http://localhost`. נדרשת הרשאה למצלמה.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## איך זה עובד

1. **הפעל מצלמה** — מאשרים גישה. המצלמה נשארת פעילה כל הזמן. תצוגה ממוזערת בפינה השמאלית-תחתונה מציגה את היד שלך עם שלד.
2. **הצבע** — הזז את האצבע המורה. הסמן הציאני העגול נע בהתאם.
3. **הוראה (hover)** — אפליקציה שמתחת לסמן מקבלת זוהר ותהודה.
4. **צביטה** — חבר את האגודל לאצבע המורה. הסמן הופך כתום, האפליקציה נפתחת בחלונית קופצת.
5. **סגירה** — הזז את הסמן מעל "סגור" וצבוט שוב.

## סטטוס בראש הדף

- **מצלמה** — ירוק כשהמצלמה פעילה
- **יד** — ירוק כשמזוהה יד בפריים
- **צביטה** — כתום כשהאגודל והאצבע נוגעים

## טכנולוגיה

- **MediaPipe Hands** (Google) — 21 נקודות ציון ליד בזמן אמת
- מיפוי מהמצלמה למסך עם השתקפות אופקית (front camera mirror)
- Smoothing אקספוננציאלי על הסמן (alpha=0.3) להפחתת רעידות
- זיהוי צביטה עם hysteresis: מחבר ב-0.40, מנתק ב-0.55, יחס ביחס לגודל היד
- **Web Audio API** — צלילי hover/click קצרים

הכל רץ מקומית בדפדפן. שום נתון לא יוצא מהמכשיר.
