# Hand Tracking AR

אתר לזיהוי יד בזמן אמת דרך מצלמת המכשיר, עם שרטוט שלד (קווים ונקודות) על היד בסגנון AR / מצלמת אבטחה.

## שימוש

פתח את `index.html` בדפדפן מודרני (Chrome / Edge / Firefox / Safari) ולחץ על "הפעל מצלמה". נדרשת הרשאת גישה למצלמה.

> הערה: דפדפנים מאפשרים `getUserMedia` רק בהקשר מאובטח — `https://` או `http://localhost`. אם אתה פותח את הקובץ מקומית, הרץ שרת פשוט:
>
> ```bash
> python3 -m http.server 8000
> ```
>
> ואז גש ל-`http://localhost:8000`.

## טכנולוגיה

- **MediaPipe Hands** (Google) - זיהוי 21 נקודות ציון ליד בזמן אמת
- **Canvas 2D** - שרטוט הקווים, הנקודות ותיבת הגבול
- HTML/CSS/JS טהור ללא תלות ב-build tools

## תכונות

- זיהוי עד 2 ידיים בו-זמנית (שמאל/ימין עם צבעים שונים)
- קווי חיבור בין 21 נקודות הציון של היד
- תיבת גבול סביב היד (כמו מצלמת אבטחה)
- HUD עם סטטוס, מונה ידיים ו-FPS
- מצב מראה, נקודות וקווים ניתנים להפעלה/כיבוי
